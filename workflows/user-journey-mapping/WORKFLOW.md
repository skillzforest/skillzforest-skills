# Workflow : parcours utilisateurs / user story mapping

## Objectif

Transformer le cadrage fonctionnel en parcours utilisateurs sur Miro, afin de rendre visible le parcours client et de préparer la présentation et la priorisation du produit.

## Skill principale

- `presales-user-journey-miro`

## Input

- document de cadrage fonctionnel du projet
- personas, boucle de valeur, user stories déjà identifiées dans le cadrage

## Processus

### 1. Vérifier le périmètre

- lire seulement le cadrage fonctionnel du projet courant
- ignorer les autres projets ou documents non liés

### 2. Dupliquer et ajuster le template

- partir du board template Miro fourni dans la skill
- créer une copie sur le compte utilisateur
- aligner les colonnes sur la boucle de valeur
- répartir les stories par persona et par priorité

### 3. Publier la carte de parcours

- donner l’URL du board à l’utilisateur
- demander à l’utilisateur de copier l’URL dans le document de cadrage fonctionnel

## Livrables

- board Miro de mapping
- URL de board exploitable pour la présentation

## Sorties utiles vers les autres workflows

- `presales-client-presentation` utilise cette carte pour la section “User Journey”
- le cadrage fonctionnel reste la source de vérité ; le Miro est un support visuel

## Garde-fous

- ne pas modifier le template original
- ne pas inventer des stories absentes
- respecter la structure du template et la logique Must have / Nice to have / Extra
- ne pas écrire directement dans le document de cadrage fonctionnel ; l’URL est relancée manuellement par l’utilisateur

## Cas d’usage typiques

- nouveau projet après cadrage fonctionnel
- itération UX à la suite d’un nouveau CR
- préparation de la présentation client
