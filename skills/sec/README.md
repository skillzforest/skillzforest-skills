# skills/sec

Skills de sécurité transverse.

Aucune skill `sec-*` n'est encore implémentée dans ce dépôt. Ce dossier est prêt à en accueillir : chaque skill doit vivre dans son propre sous-dossier `sec-<nom>/` avec au minimum un `SKILL.md` et un `skill.json`, conformément à la convention décrite dans [`skills/README.md`](../README.md).
