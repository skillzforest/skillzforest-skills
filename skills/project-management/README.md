# skills/project-management — Project Management

Track project progress: backlog, sprints, reporting, documentation.

No skill is implemented in this domain yet. Two accepted prefixes:

| Prefix | Scope |
|---|---|
| `board-*` | Backlog, tickets, sprints, progress tracking |
| `docs-*` | Documentation |

Each skill lives in its own `<prefix>-<name>/` subfolder with at least a
`SKILL.md`, per the convention in [`skills/README.md`](../README.md) and the
registry [`skills/domains.json`](../domains.json).
