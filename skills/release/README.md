# skills/release

Skills de release et de mise en production.

Aucune skill `release-*` n'est encore implémentée dans ce dépôt. Ce dossier est prêt à en accueillir : chaque skill doit vivre dans son propre sous-dossier `release-<nom>/` avec au minimum un `SKILL.md` et un `skill.json`, conformément à la convention décrite dans [`skills/README.md`](../README.md).
