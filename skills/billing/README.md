# skills/billing

Skills de monétisation et d'abonnement.

Aucune skill `billing-*` n'est encore implémentée dans ce dépôt. Ce dossier est prêt à en accueillir : chaque skill doit vivre dans son propre sous-dossier `billing-<nom>/` avec au minimum un `SKILL.md` et un `skill.json`, conformément à la convention décrite dans [`skills/README.md`](../README.md).
