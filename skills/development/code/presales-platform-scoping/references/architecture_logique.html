Architecture technique générique. Le Navigateur passe par le Frontend ; l'Application mobile se branche directement sur l'API Métier (headless). Les assets JS/CSS sont servis par le Frontend, les assets médias par une brique dédiée sous les Données ; le CDN diffuse les deux. L'API Métier encapsule les API tierces. Base d'échange, amenée à évoluer par itérations.
