# runtimes/claude-ai

Status: **verified** (see [`runtime.json`](runtime.json)).

Claude.ai and Claude Desktop's custom Skills feature imports a zip containing a `SKILL.md` folder — the same format as [`../claude-code/`](../claude-code/), just delivered as an upload instead of a filesystem copy (`installStrategy: "upload"`).

## Building

```bash
npm run build:skill -- av-devis claude-ai
# -> dist/skills/av-devis/claude-ai/av-devis-0.1.0.skill  (upload this file to Claude.ai)
```

The `.skill` extension and the internal `<skill-id>/...` folder nesting match the format this repo used to maintain by hand under `skills-claude/`. It is now generated by [`scripts/lib/adapters.js`](../../scripts/lib/adapters.js) (`adaptUpload`) instead of being zipped manually — the source of truth stays `skills/`.
